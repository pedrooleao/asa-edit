# Asa Edit

Controle da Behringer WING (Compact) para Mac, em modo escuro, mais simples que o
WING Edit: mixer, retornos dos músicos pelo celular, roteamento visual, efeitos e
shows no mesmo formato .snap do WING Edit.

## Instalar no Mac

Baixe o **.dmg** da [última versão](https://github.com/pedrooleao/asa-edit/releases/latest),
arraste o Asa Edit para Aplicativos e, na primeira vez, abra com **botão direito → Abrir**
(o app não é assinado pela Apple). Permita a rede local quando o macOS perguntar.
Precisa de Mac com Apple Silicon.

## Desenvolver

Veja `CLAUDE.md` para rodar, `docs/PLANO.md` para o roteiro e o que falta confirmar
na mesa, `docs/DESIGN.md` para o visual e `docs/PROTOCOLO.md` para o protocolo.
